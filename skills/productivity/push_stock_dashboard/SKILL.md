# Stock Dashboard Data Fetch

## Goal
Provide a robust, reusable workflow to obtain the latest price and basic metrics for a Taiwanese stock ticker, suitable for inclusion in HTML dashboards generated by the `push_stock_dashboard` skill.

## Primary Source (preferred)
- **Yahoo Finance API** (`https://query1.finance.yahoo.com/v7/finance/quote?symbols=<ticker>.TW`)
- Returns JSON with `regularMarketPrice` and `regularMarketChangePercent`.
- *Pitfall*: May return **HTTP 429** or **Unauthorized** due to rate limits.

## Fallback Source
- **TWSE (Taiwan Stock Exchange) daily report**
  - URL: `https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=YYYYMMDD&stockNo=<ticker>`
  - JSON payload with `data` array; the last element holds the most recent day's values.
  - Useful fields: `收盤價` (close price), `漲跌價差` (price diff), `日期`.

## Workflow
1. Attempt Yahoo fetch via `fetch_yahoo.py`.
2. On failure (non‑zero exit or missing price), log and switch to TWSE method.
3. TWSE fetch example (Python):
```python
import json, urllib.request

def fetch_twse(ticker):
    url = f'https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=20230824&stockNo={ticker}'
    with urllib.request.urlopen(url) as resp:
        data = json.load(resp)
    last = data['data'][-1]
    fields = data['fields']
    info = dict(zip(fields, last))
    return {
        'date': info['日期'],
        'close': info['收盤價'].replace(',', ''),
        'diff': info['漲跌價差']
    }
```
4. Populate a simple HTML template (`templates/stock_dashboard.html`) with the fetched values.
5. Commit and push using the existing `push_stock_dashboard` workflow.

## Pitfalls & Tips
- Insert a short `time.sleep(1)` before retrying Yahoo to mitigate 429.
- Use `datetime.now().strftime('%Y%m%d')` for the TWSE `date` parameter.
- Ensure UTF‑8 handling for Chinese field names.
- If both sources fail, raise an exception; do not generate a stale dashboard.
